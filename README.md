# Museum Curator

This is an updated version of the mod Museum Curator by dividesBy0/immortius that provides assistance with building a minecraft museum to display every item available in Minecraft.

## Developing

This project requires [JDK 17](https://adoptium.net/) & uses the [MultiLoader Template](https://github.com/jaredlll08/MultiLoader-Template) provided by [jaredlll08](https://github.com/jaredlll08).
